Physics is not a constant

Robot policies are trained assuming the world's physics stays fixed. Drag the sliders below — same scene, same action, only one physical factor changes each time — and watch outcomes diverge. If physics matters this much, we should measure it.

Each card is one physical factor; each slider runs three levels from the default outward.

Manipulation benchmarks randomize what the world looks like — backgrounds, lighting, clutter — but keep what the world is like fixed. RoboTwin-Phys turns the world's physical parameters into controllable, labelable variables: 13 physical factors on 50 bimanual tasks, with per-episode ground truth down to 250 Hz contact-force logs and failure timelines.

RoboTwin 2.0 randomizes vision. We randomize physics.

EXISTING

Visual randomization

  • Background textures & lighting
  • Clutter & distractors
  • Table height (±3 cm)
  • Language instructions

Physics stays hard-coded: friction 0.5, restitution 0, fixed masses, level table, pinned camera.

THIS WORK

Physical randomization

  • Contact: friction, restitution, damping
  • Object: mass, center of mass, geometry
  • Workspace: tilt, height, external force
  • Sensor: camera distance & angle

Every factor is controllable, swept in tiers, and labeled with exact ground-truth values.
